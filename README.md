## 🎛️ FastFlags Editor — The Control Room

FastFlags are the quiet levers behind Roblox's visual and behavioral engine. Most players never see them; Fishstrap lines them up like the sliders on a mixing console and hands you the headphones.

Inside the editor you will find:

- **Categorized flags** — rendering, physics, networking, UI, and experimental groups.
- **Search that actually searches** — fuzzy matching so "shadowqual" still finds `ShadowQuality`.
- **Presets** — Balanced, Performance, Cinematic, and Legacy profiles ready out of the box.
- **Profiles per game** — different flags for different experiences, switched automatically.
- **Diff view** — see exactly what changed between your last two configurations.
- **Import and export** — share a flag set with a friend as a single text block.

The editor does not guess on your behalf. It presents, you decide. Every change is reversible with one click, and every preset is documented so you know what you are switching on.

## 🚀 FPS Unlocker — Beyond the Horizon

A frame rate cap is a fence. Some players are perfectly happy inside the fence; others want to know what the grass looks like on the other side. The FPS unlocker removes the fence — carefully, with awareness of thermal limits and stability.

Highlights:

- **Configurable ceilings** — from modest bumps to extreme values, for hardware that can actually keep up.
- **Adaptive smoothing** — optional frame pacing to reduce visible stutter.
- **Hardware awareness** — alerts you when your GPU or CPU is being pushed past comfortable limits.
- **Per-game overrides** — a competitive shooter and a building sandbox have different needs.
- **On-screen counter** — lightweight overlay showing live FPS without any external tooling.

Higher frame rates are not a magic trick; they are the result of your hardware finally being allowed to speak at full volume.

## 🪟 Multi-Instance — Split Yourself Across Worlds

Sometimes one session is not enough. Maybe you are testing a build in one world while socializing in another. Maybe a sibling wants the machine too. Multi-instance support lets several Roblox sessions coexist.

- **Isolated instances** — each session keeps its own configuration.
- **Named windows** — tag each instance so you never confuse them.
- **Resource governor** — optional caps per instance to prevent one session from hogging the machine.
- **Quick spawn** — launch a fresh instance with a keyboard shortcut.
- **Safe-mode** — if the system feels strained, Fishstrap throttles new spawns automatically.

## 🔤 Custom Font Loading — Typography as Identity

The default font is fine. Fine is the enemy of memorable. Fishstrap's font loader lets you replace the interface typeface with any supported font file you have on hand.

- **Live preview** — see the effect before applying it.
- **Fallback chains** — if a glyph is missing, another font catches it.
- **Per-region overrides** — different fonts for chat, menus, and nametags if you wish.
- **Safe unloading** — one click returns you to the default typeface.

Typography is the tone of voice of an interface. Choose yours.

## 🚀 Getting Started Without the Hassle

You will not find a wall of terminal commands here. Fishstrap is intended to be approachable:

1. Fetch the launcher package through the official distribution channel referenced at the top of this document.
2. Unpack the archive into a folder of your choosing — nothing writes to system directories without asking.
3. Run the launcher executable. First launch walks you through a short, friendly setup wizard.
4. Pick a preset (Balanced is a good starting point) or dive straight into the FastFlags editor.
5. Launch Roblox from within Fishstrap and enjoy the adjusted experience.

If anything feels off, the built-in diagnostics panel will tell you what it sees. The 24/7 support team can read that panel's output and guide you from there.

## ⚙️ Configuration Reference

Fishstrap stores its configuration in a human-readable file structure. Nothing is obfuscated.

- **Profiles** — named sets of settings, switchable in one action.
- **Flags** — a key/value mapping matching Roblox's internal flag names.
- **Fonts** — references to installed typefaces, with fallback ordering.
- **Instances** — per-instance memory and priority settings.
- **Mods** — a manifest listing active and inactive mod directories.

Because everything is documented and reversible, experimentation carries no real risk.

## ❓ FAQ

**Is Fishstrap safe to use?**
Yes. Builds are signed, changelogs are public, and updates flow through verified distribution only.

**Will using FastFlags put my account at risk?**
FastFlags manipulate local client behavior. Fishstrap ships with presets known to be conservative by default. Extremely unusual combinations carry their own risks — read the docs before experimenting.

**Does multiboxing violate Roblox rules?**
Review Roblox's current Terms of Use. Fishstrap provides the technical capability; using it responsibly is your decision.

**Can I roll back to an earlier version?**
Yes. Every release is archived and can be reinstalled alongside the current one.

**How often is Fishstrap updated?**
The 2026 line receives regular maintenance updates, typically aligned with Roblox client changes.
